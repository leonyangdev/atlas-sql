### V0-S06-T02 Gold SQL 格式规范

每道有 SQL 的题目包含：
- `question_id`：唯一 ID，命名规则 `{split}-{序号}`
- `gold_sql`：固定日期字面量，不使用 NOW()
- `required_tables / required_columns`：用于覆盖率分析
- `identity`：执行身份（public / analyst_north / store_bj_001 等）
- `is_ordered`：有序查询用行序比较，无序用多重集

每道拒绝/澄清题包含：
- `expected_action`："reject" 或 "clarify"
- `rejection_reason` 或 `clarification_hint`

### V0-S06-T03 数据集分离

- `train`：开发 few-shot / prompt 调优；全部可收录 VQR
- `tune`：模型调优；禁止收录 VQR
- `test`：锁定；`locked: true`；禁止收录 VQR 和 few-shot

`verify_no_leak` 函数检查训练集与测试集之间无 ID 重叠：

两项均通过，无泄漏。

### V0-S06-T04 Gold SQL 执行与比较工具

比较规则（已在比较器代码和 README 中一致声明）：
- **无序**：多重集（行顺序不影响，重复行数量必须一致）
- **有序**：`is_ordered=True`，精确按行序比较
- **金额**：Decimal 精确比较，无浮点容差
- **NULL**：None == None，None ≠ 空字符串
- **空结果**：Gold 0 行 → 模型也必须 0 行

执行限制：
- 只读身份（`atlas_reader`），事务级只读
- `statement_timeout` 防大查询
- `LIMIT max_rows` 防超大结果集

```bash
# 验证 train 集 Gold SQL 可执行（需要真实数据库 + tiny 数据）
ATLAS_BUSINESS_DATABASE_URL="postgresql://atlas_reader:...@localhost:5433/nova_retail" \
uv run python scripts/run_benchmark.py --split train

# 验证可重复性
uv run python scripts/run_benchmark.py --split train --verify-repeatability
```

测试入口：`tests/test_benchmark.py` 34 个测试全部通过（不依赖真实数据库）。
