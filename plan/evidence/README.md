# 验收证据

已完成任务按故事记录在本目录；计划中的勾选必须能对应到这里的真实命令、输出和限制。

每个任务可建立 `V0-S01-T01.md`，也可按故事合并 `V0-S01.md`，但必须逐项列出任务 ID 和证据。不要提交密钥、个人信息或大结果集。

## 记录模板

```markdown
# V0-S01-T01 验收记录

- 日期 / 执行者：
- 任务及依赖：
- 代码版本（没有 Git 时记录文件与内容摘要）：
- 环境 / 数据 / schema / 语义 / 模型版本：
- 真实入口与关键调用关系：
- 命令与实际输出摘要：
- 正常场景：
- 失败或边界场景：
- 对应验收要求：
- 限制与未通过项：
- 学习站更新位置：
- 结论：通过 / 未通过（说明依据）
```

如果没有真实运行条件，记录“未验证”并保留原任务未勾选。一个故事级证据可覆盖多个任务，但不能用笼统“全部通过”替代逐项对应。
