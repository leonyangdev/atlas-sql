# Benchmark v1 — NovaRetail NL2SQL

## 数据集说明

- **数据版本**：dataset `v0.1.0`，schema `001`，seed `20260908`
- **业务时钟**：`2026-06-30T16:00:00Z`（数据截止点，查询中的"最近/本期"均相对此时钟）
- **总题量**：120 道（train 60 + tune 30 + test 30）
- **问题家族分离**：同一业务概念（如"销售额"）的变体题目不跨分割线分配

## 分割规则

| 文件 | 用途 | 题量 | 可用于 Verified Query Repository |
|------|------|------|----------------------------------|
| `train.yaml` | 开发阶段 few-shot 示例、prompt 调优 | 60 | ✅ 可全部收录 |
| `tune.yaml` | 指标/模型调优，不参与最终评测 | 30 | ❌ 禁止收录 |
| `test.yaml` | 锁定，只用于最终评测 | 30 | ❌ 禁止收录 |

**严禁**把 `tune.yaml` 或 `test.yaml` 的题目或近似改写收录到 Verified Query Repository，否则会污染评测基准。

## 比较规则

比较工具（`scripts/run_benchmark.py`）：
- 无序查询：按集合比较，不依赖行顺序
- 有序查询（含 ORDER BY）：按序列比较
- 金额：精确到分（Decimal，无浮点容差）
- NULL：`NULL != NULL`，`NULL == NULL` 需在 Gold SQL 里写 IS NULL
- 空结果：Gold SQL 返回 0 行时，模型也必须返回 0 行
- 拒绝题：不执行 SQL，检查模型是否返回澄清信号而不是错误 SQL
- 权限题：检查 Gold SQL 是否包含 WHERE 行过滤或列脱敏

## Gold SQL 执行规则

- **只读身份**：使用 `atlas_reader` 账户，默认只读事务
- **固定数据快照**：评测前必须用 tiny 配置重置数据（保证 seed 一致）
- **固定业务日期**：Gold SQL 中不使用 `NOW()`，全部使用固定日期字面量
- **结果摘要**：只记录行数和校验和，不存储完整查询结果
